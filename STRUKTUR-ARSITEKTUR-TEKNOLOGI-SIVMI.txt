STRUKTUR BERDASARKAN ARSITEKTUR TEKNOLOGI SIVMI CRM
===================================================

Pemetaan file menurut node runtime, state, jaringan, deployment, dan operasi.

Catatan:
- Struktur ini adalah proyeksi logis; file fisik tidak dipindahkan atau digandakan.
- Satu file dapat muncul pada beberapa kelompok jika memiliki fungsi lintas arsitektur.
- Dokumentasi, draw.io, dependency pihak ketiga, cache, dan log tidak dicantumkan.
- Baseline 8 September 2026: API Sekolah dan tile OpenStreetMap memerlukan HTTPS keluar; Leaflet disajikan lokal; API siswa memakai HTTPS dan Bearer token.
