STRUKTUR BERDASARKAN ARSITEKTUR APLIKASI SIVMI CRM
==================================================

Pemetaan source modular monolith menurut layer dan tanggung jawab aplikasi.

Catatan:
- Struktur ini adalah proyeksi logis; file fisik tidak dipindahkan atau digandakan.
- Satu file dapat muncul pada beberapa kelompok jika memiliki fungsi lintas arsitektur.
- Dokumentasi, draw.io, dependency pihak ketiga, cache, dan log tidak dicantumkan.
- Baseline 8 September 2026: StudentController, ListStudentRequest, StudentResource, students:read, dan kontrol RBAC transaksi menjadi bagian aplikasi aktif.
